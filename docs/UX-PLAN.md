## 工作流分类规则

- 记录字段 `category`（字符串，≤40 字）。预设 5 类；自定义分类允许任意名称。
- 导入时按节点推断建议分类（SaveImage→生图；VHS_VideoCombine→视频；音频节点→音频；3D/模型节点→模型；LoadImage+inpaint/img2img→编辑），用户在编辑器里确认/修改。
- 输入框工作流下拉按分类分组；只展示有内容的分类。
- 分类用于首页「生成图片/视频/声音/模型」与「编辑」入口的过滤。

## 工作区首页

- 触发：当前工作区没有选中会话，或选中会话尚无任何 turn。
- 内容：时间问候（早上/下午/晚上/夜深）＋「现在想干什么呀？」＋【编辑】【生成】；点生成展开【生成图片】【生成视频】【生成声音】【生成模型】（无对应分类工作流时置灰并给「去导入工作流」入口）。
- 选择后：写入 composer 的工作流/分类，聚焦输入框；直接打字发送则按当前模式。
- 后续（v2.4）在首页加「最近生成」资产条。

- 纯文本模板插入光标处；带变量时先弹小表单填写；「保存为模板」在输入框菜单。

## Agent 临时会话（v2.4 提案，待确认）

把 ✨ Agent 模板从「一次性转换」升级为「可多轮的临时会话」，但不进工作区历史。

### 交互

1. 输入框打 `@` → 面板分组：**✨ Agent 模板**（置顶）/ 提示词模板 / 参考图。
2. 选中 Agent 模板 → 右侧滑出**抽屉式临时会话**（可拉宽、可拖动主区图片进去），输入框进入 Agent 模式。
3. 会话布局与正常聊天一致：**用户消息在右、Agent 回复在左**；支持连续追问（带上此前轮次）。
4. 每条用户消息可附带图片；每轮显示耗时与字数。
5. Agent 回复可**整段**或**选中片段**送入输入框，成功后抽屉关闭（也可保持打开继续追问）。
6. 抽屉内工具：清空 / 重新开始 / 取消当前请求 / 复制 / 重试。
7. 抽屉状态按「会话 + 模板」存在 localStorage，刷新可恢复；**不写入工作区会话历史**。

### 服务端

- `agent.run` 接受 `messages: [{role, text?, imageBase64?}]`（多轮、无状态）；保留单轮 `input` 兼容。
- 多轮上下文由客户端维护并按需截断（保留最近 N 轮 + 模板 system prompt）。
- DSH 通道：每轮图片仍走附件服务；API 通道：按 OpenAI 多模态 messages 发送。

### 保留单轮快路径

模板加 `mode: 'single' | 'chat'`：

- `single`（默认）→ 当前的行内小面板，一问一得；
- `chat` → 抽屉式临时会话，可多轮打磨。

这样"反推提示词"这类一次性任务不被迫进聊天界面，而"扩写 / 反复改风格"可以用会话。
