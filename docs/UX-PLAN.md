# AI 创作工作台 · 交互方案 v3（已定稿）

状态：决策已确认，按 v2.1 → v2.5 分期实施。

## 已确认的决策

1. **Agent 模型：两条路都做**
   - 主路径：插件设置里独立配置 OpenAI 兼容的 Agent 接口（`baseUrl` / `apiKey` / `model`，可默认复用生图 API 的 baseUrl/key）。
   - 增强路径（先验证宿主暴露面）：若 DSH 宿主能提供当前会话模型，则作为「使用 DSH 模型」选项加入。
2. **首页「编辑」入口**：先选图/上传 → 再选「编辑」分类工作流 → 新会话预置编辑意图。
3. **模板作用域**：全局模板库 + 工作区收藏（不复制模板本体）。
4. **工作流分类**：固定 5 类（`edit` 编辑 / `image` 生图 / `video` 生视频 / `audio` 生音频 / `model` 生模型），**允许自定义分类名**。

## 信息架构

四标签活动栏（侧栏顶部）：工作区 / 资产库 / 模板 / 工作流；主区域跟随标签切换（工作区画布保持挂载，切换用隐藏而非卸载）。

- 工作区：会话树（搜索/状态角标/置顶）+ 主区域首页问候或会话画布 + 输入框
- 资产库：筛选/搜索/排序 + 主区网格 + 右侧详情抽屉（v2.4）
- 模板：分类列表 + 编辑器/预览（v2.2）
- 工作流：按分类分组的工作流管理（v2.1），后续加健康检查/克隆/导入导出

## 工作流分类规则

- 记录字段 `category`（字符串，≤40 字）。预设 5 类；自定义分类允许任意名称。
- 导入时按节点推断建议分类（SaveImage→生图；VHS_VideoCombine→视频；音频节点→音频；3D/模型节点→模型；LoadImage+inpaint/img2img→编辑），用户在编辑器里确认/修改。
- 输入框工作流下拉按分类分组；只展示有内容的分类。
- 分类用于首页「生成图片/视频/声音/模型」与「编辑」入口的过滤。

## 工作区首页

- 触发：当前工作区没有选中会话，或选中会话尚无任何 turn。
- 内容：时间问候（早上/下午/晚上/夜深）＋「现在想干什么呀？」＋【编辑】【生成】；点生成展开【生成图片】【生成视频】【生成声音】【生成模型】（无对应分类工作流时置灰并给「去导入工作流」入口）。
- 选择后：写入 composer 的工作流/分类，聚焦输入框；直接打字发送则按当前模式。
- 后续（v2.4）在首页加「最近生成」资产条。

## 模板与 @

- 输入框 `@` 唤起统一下拉：分组「提示词模板」+「参考图」；继续输入过滤；↑↓/Enter。
- 纯文本模板插入光标处；带变量时先弹小表单填写；「保存为模板」在输入框菜单。
- Agent 模板（v2.3）：模板带 ✨ 徽标；选中后输入框进入 Agent 模式（边框变色 + chip + 占位文案变化）；输入文字/图片 → 「生成提示词」→ 结果卡（可编辑）→ 确认插入；输出可含正向+负向。
- Agent 模板在模板编辑器内含「Agent 配置」页签与「试跑」。

## 数据与接口（新增）

- 工作流：`category` 字段（v2.1）
- 模板：`templates.json` + `template.list/save/delete/import/touch`（v2.2）
- Agent：设置 `agent {baseUrl, apiKey, model}` + `agent.run`（v2.3）
- 资产：`assets-index.json` + `asset.list/favorite/delete`（v2.4）
- 会话意图：conversation `meta {intent, category}`（v2.1 起）
- 删除策略：回收站（软删）
