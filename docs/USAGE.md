## 1. 安装与更新

### 安装

在 DSH 的插件页粘贴以下任一规格：

```sh
# GitHub（推荐，版本最新）
dsh plugin --profile web add github:LEAFCHINA/dsh-creation-workbench

# npm（发布后可用）
dsh plugin --profile web add dsh-creation-workbench
```

也可以：**插件 → 添加插件 → 安装** → 粘贴包名 / GitHub 规格 / `.tgz` 路径。

安装完成后左侧栏会出现「**AI 创作工作台**」入口。如果没出现，刷新页面。

### 更新

```sh
dsh plugin --profile web remove dsh-creation-workbench
dsh plugin --profile web add github:LEAFCHINA/dsh-creation-workbench
```

> 从 1.x（旧名 `dsh-image-workbench`）升级：先 `remove dsh-image-workbench` 再装新包。首次启动会自动把旧数据目录复制到新目录。

### 验证是否生效

打开插件 → 底部「设置」旁边状态点显示 **已配置** 或 **已配置 ComfyUI** 即正常。

## 2. 第一次打开：配置后端

打开工作台 → 左侧栏底部 **⚙ 设置**。

两种后端可以**同时配置**，在对话框里随时切换。

### 2.1 第三方生图 API

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| **API 地址** | 到 `/v1` 为止，不要带 `/images/generations` | `https://api.openai.com/v1` |
| **API Key** | 明文存在本机 `settings.json`，界面只回显掩码 | `sk-...` |
| **模型列表** | 手动添加，或点「从上游拉取」 | `gpt-image-2`、`grok-imagine-image-2.0` |
| **接口方言** | 决定请求格式，选错会报参数错误 | `openai-images` / `xai-image` / 自动 |
| **默认参数** | 默认模型、张数、比例、尺寸、分辨率、质量 | — |

**代理**：如果你的 API 需要走代理，在「代理」一栏填写（只作用于本插件请求）。点「扫描」可自动探测本机常见代理端口。

填完点 **保存**。状态点变绿即连通性正常（可先点「检测」验证）。

### 2.2 本机 ComfyUI

前提：本机已经跑起来 ComfyUI（默认 `http://127.0.0.1:8188`）。

1. 设置 → **ComfyUI** 区域 → 填 **服务地址**：`http://127.0.0.1:8188`（**不要**带 `/v1`）。
2. 点 **检测** → 显示版本号即连通。
3. 接着按下一节 [导入 ComfyUI 工作流](#4-导入-comfyui-工作流详细) 操作。

> ComfyUI 请求**永远直连**，不会走上面配置的代理。

## 3. 生成第一张图

1. 左侧「工作区」标签，点 **＋** 新建一个工作区，或直接用「默认工作区」。
2. 点 **＋ 新会话**（或在主区首页点「生成」）。
3. 主区首页会显示问候和两个按钮：
   - **编辑**：进入图片编辑流程（当前预选「编辑」类工作流）
   - **生成**：展开「生成图片 / 生成视频 / 生成声音 / 生成模型」
   
   选任一分类，会自动选中该分类下**最近使用的工作流**（图片分类没有工作流时回退到 API 模型），光标落到输入框。
   
   也可以**不点按钮**，直接在输入框写提示词发送，走当前已选模式。
4. 输入框下方控制条：
   - **模型下拉**：API 模型 + ComfyUI 工作流（按分类分组，形如 `工作流 · 生图`）
   - **张数**：只有工作流暴露 `batch_size`、或走 API 模式时才出现
   - **比例 / 尺寸 / 分辨率 / 质量**：API 模式专有
   - **工作流参数行**：勾选的参数会换行排列，数值型带「随机」开关
5. 写提示词 → **Enter 发送**（`Shift+Enter` 换行）。
6. 生成中会显示进度；完成后图片出现在画布，并落盘到保存目录。

## 4. 导入 ComfyUI 工作流（详细）

这是本插件最核心的能力：**把 ComfyUI 工作流的节点输入变成对话框里的参数**。

### 4.1 在 ComfyUI 里导出 API 格式

1. 在 ComfyUI 界面搭好工作流。
2. 右上角菜单 → **Save (API format)** / **保存（API格式）**。
   > 普通「Save」导出的 UI 格式会被插件**故意拒绝**，因为两种格式结构完全不同。
3. 得到一个 `.json` 文件。

### 4.2 在插件里导入

1. 设置 → ComfyUI 区域 → **导入工作流** → 选择刚才的 `.json`。
2. 插件会解析节点并弹出 **参数编辑器**。

### 4.3 参数编辑器怎么用

编辑器是**两栏布局**：

```
┌─────────────┬──────────────────────────────┐
│ 节点列表     │  节点详情：勾选要暴露的输入     │
│ (可搜索)     │  名称 / 类型 / 范围 / 默认值    │
└─────────────┴──────────────────────────────┘
```

**左栏**：按节点列出工作流里所有节点，带类型名，支持搜索。带「输出」标记的是输出节点。

**右栏**：点某个节点后，列出它所有可暴露的输入。每个输入：

| 设置 | 说明 |
| --- | --- |
| 勾选 | 是否在对话框里显示 |
| **名称** | 对话框里显示的中文名，如「步数」 |
| **类型** | 文本 / 整数 / 小数 / 布尔 / 下拉 |
| **最小 / 最大 / 步长** | 数值型的范围限制 |
| **选项** | 下拉类型的候选项（从 ComfyUI 元数据自动带出） |
| **默认值** | 初始值 |
| **随机** | 勾选后每次生成随机取值（常用于 seed） |
| **角色** | 「主提示词」表示接收对话框文字 |

**提示词绑定**：必须有一个输入被打上「主提示词」。工具会自动建议（空的 TextEncode / PrimitiveString 节点）。如果没绑定，对话框会显示可点击的警告，点了会引导你回来绑定——**只会丢字不会静默成功**。

**参数顺序**：工具栏下方有「对话框参数顺序」预览，已选参数显示成小卡片：
- 拖动卡片调整顺序
- 或用卡片上的 **↑ ↓** 按钮
- **✕** 移除该参数

顺序就是它们在对话框里的排列顺序。

### 4.4 分类

编辑器顶部有 **分类** 下拉：

- 预设：**编辑 / 生图 / 生视频 / 生音频 / 生模型**
- **自定义…**：填入任意名称（如「3D 场景」）

插件会根据输出节点**自动建议**分类：
- `SaveImage` → 生图
- `VHS_VideoCombine` / 视频输出 → 生视频
- 音频输出节点 → 生音频
- 3D / 网格输出 → 生模型
- `LoadImage` / inpaint / img2img 链路 → 编辑

建议只是初值，你随时可以改。

### 4.5 保存与使用

1. 填 **工作流名称**，选 **分类**，点 **保存**。
2. 回到对话框 → 模型下拉里出现 `工作流 · <分类>` 分组下的该工作流。
3. 选中后，暴露的参数会出现在输入框下方，可调、可随机。
4. 写提示词发送。

> **修改已有工作流**：设置里点该行的「编辑」→ 调整参数/顺序/分类 → 保存。已保存的勾选会被准确保留，不会重新乱勾。

### 4.6 工作流管理

**工作流** 标签页按分类分组展示所有工作流，每张卡片可以：

- **使用** → 切换到该工作流并回到工作区
- **编辑参数** → 打开设置里的编辑器
- **删除** → 二次确认后删除

## 5. 工作区、会话与草稿

### 结构

```
工作区（可多个）
└── 会话（每个工作区多个）
    └── 多次生成（turn）→ 图片
```

- 顶部「＋」新建工作区；工作区行右侧「+」新建会话；「⋯」重命名/删除。
- 每个会话显示相对时间。

### 会话级记忆（重点）

切换会话时，以下内容**各自独立保存并恢复**：

- ✅ 输入框里**没发送的提示词**
- ✅ 所选**模型 / 工作流**
- ✅ 所有**参数值**与**随机开关**
- ✅ **张数**

所以：会话 A 用工作流 A、会话 B 用工作流 B，来回切换不会串。刷新页面也不会丢（存在浏览器 localStorage）。

### 空会话的首页

新会话或没有生成记录的会话，主区显示：

```
早上好~ 现在想干什么呀？
   [ ✎ 编辑 ]   [ ✦ 生成 ]
```

问候语按时间变化（早上好 / 中午好 / 下午好 / 晚上好 / 夜深了）。

## 6. 提示词模板

适合把常用的长提示词骨架存起来复用。

### 6.1 新建模板

1. 侧栏 **模板** 标签 → 主区显示模板编辑器。
2. 填写：

| 字段 | 说明 |
| --- | --- |
| **模板名称** | 如「复古胶片人像」 |
| **分类** | 自定义文字，如 人像 / 产品 / 海报（用于筛选） |
| **模板类型** | 文本模板 / ✨ Agent 模板 |
| **绑定工作流分类** | 可选，标记这个模板适合哪类工作流 |
| **模板内容** | 提示词正文，可用 `{{变量}}` |
| **变量默认值** | 内容里出现 `{{主体}}` 就自动列出可填默认值 |
| **预览** | 实时显示填充后的效果 |

3. 点 **保存模板**。

### 6.2 在输入框调用（`@`）

1. 在输入框输入 **`@`** → 弹出模板面板。
2. 继续输入文字可**搜索**（匹配名称/分类/内容）。
3. **↑ ↓** 选择，**Enter** 插入，**Esc** 或点外部关闭。
4. 带变量的模板：先弹出小表单填写每个变量 → 点「插入」。
5. 插入位置是 `@` 所在处（光标处）；插入后使用次数 +1。

### 6.3 存为模板

两种入口，效果相同：

- 输入框控制条的 **「存为模板」** 按钮
- `@` 面板底部的 **「＋ 把当前输入存为模板」**

都会把当前输入框内容带进模板编辑器，起个名字保存即可。

## 7. Agent 模板详解

Agent 模板不是固定文本，而是**叫模型帮你生成提示词**。典型用法：一句话扩写、图片反推提示词、翻译润色、负面词生成。

### 7.1 先配置 Agent 模型

模板标签页顶部有 **「Agent 模型（✨ 模板使用）」** 面板，两种来源：

#### 来源 A：Agent API（OpenAI 兼容）

| 字段 | 说明 |
| --- | --- |
| **Agent API 地址** | 到 `/v1` 为止；**留空则复用生图 API 地址** |
| **Agent API Key** | 留空则复用生图 API Key；已配置时只显示掩码 |
| **Agent 模型** | 如 `gpt-4o-mini`、`qwen-plus` |

适合：需要**图片反推**（多模态）、或想用外部模型。

#### 来源 B：DSH 模型（无需 API Key）

1. 来源切到 **「DSH 模型（实验）」**
2. 点 **刷新 DSH 模型** → 自动读取宿主可用 provider / model
3. 选 **Provider** → 选 **Model**（如 `DeepSeek` → `DeepSeek-V4.1-Flash`）
4. 点 **保存 Agent 设置**

适合：不想配 Key、想复用 DSH 里已有的模型额度。
限制：**只支持文字输入**，不能用于图片反推。

点 **测试连接** 会返回探测结果（检测到哪些服务 / 是否可用）。

### 7.2 创建 Agent 模板

新建模板 → 模板类型选 **「✨ Agent 模板」**，然后配置：

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| **Agent System Prompt** | 模型的身份与规则 | `你是资深 AI 视觉提示词工程师，只输出提示词正文…` |
| **Agent 用户模板** | 用户输入如何拼进请求，`{{input}}` 是占位 | `根据以下输入生成最终提示词：{{input}}` |
| **输入类型** | 文字 / 图片（可多选） | 图片反推就勾「图片」 |
| **输出格式** | 单一提示词 / 提示词 + 负面词 | — |
| **模型覆盖** | 可选，仅本模板用别的模型 | 留空用全局 Agent 模型 |

保存后在模板列表里带 **✨** 标记。

### 7.3 使用 Agent 模板

1. 输入框输入 **`@`** → 选那个 ✨ 模板。
2. 输入框**边框变色**，上方弹出 Agent 面板：

```
✨ 反推提示词                    ×
┌─────────────────────────────┐
│ 描述你的想法…                 │
└─────────────────────────────┘
[选择图片] 或直接粘贴图片
[ 取消 ]              [ 生成提示词 ]
```

3. 输入文字，或点「选择图片」/ 直接 **Ctrl+V 粘贴图片**（需该模板勾了「图片」输入）。
4. 点 **生成提示词**（或 Enter）。
5. 结果出现在**可编辑结果卡**中：
   - 可直接改文字
   - **[重新生成]** 再跑一次
   - **[确认插入]** 写入输入框（退出 Agent 模式）
6. 确认后**再点发送**才会真正生成图片——中间留了检查环节。

### 7.4 推荐内置模板配置

| 模板名 | 输入 | System Prompt 要点 |
| --- | --- | --- |
| 提示词扩写 | 文字 | 把一句话扩写成包含主体/构图/光线/材质/风格/氛围的完整提示词 |
| 反推提示词 | 图片 | 分析图片的构图、光线、色调、镜头，输出可直接用于生图的提示词 |
| 负面词生成 | 文字 | 根据场景输出常见缺陷负面词，逗号分隔 |
| 英文润色 | 文字 | 把中文提示词翻译成自然的英文提示词，保留原意 |

## 8. 任务、排队、取消与重试

### 单个会话内

- 生成中的卡片显示：**排队中 / 排队第 N 位 / 生成中 · xx%**
- 卡片右上角 **⏹** 可取消
- 分组头也有「取消」按钮
- 失败卡片提供 **重试** 和 **删除**

### 跨会话任务面板

顶栏 **「任务」** 按钮（有任务时显示数量并变为高亮）：

- 列出**所有会话**进行中/排队的任务
- 每行显示：工作流名、所属工作区 › 会话、提示词摘要、进度条、当前阶段（排队第 N 位 / 已用 N 秒）
- 可直接 **取消**

> 数据来自宿主内存，**刷新页面后依然在**。

### 计时规则

- **排队中**的任务不计时，只显示排队位次
- **执行中**的任务从它**真正开始执行**的时间计时，各自独立
- 本地 ComfyUI 任务**没有总超时**（首次加载模型可能要几分钟），只显示「已用 Ns」

## 9. 图片与文件管理

### 保存位置

设置 → **素材保存目录**（默认 `%USERPROFILE%\Pictures\dsh output`）。

磁盘结构：

```
保存目录/
└── 工作区名/
    └── 会话名/
        └── <图片ID>.png
```

### 图片操作

点击画布图片 → 详情浮层：

- 查看提示词、模型/工作流、参数、种子、尺寸、耗时
- **保存副本**（另存为到另一个目录）
- **打开目录**、**复制路径**
- **用作参考图**（API 模式）
- **局部重绘**（API 模式；ComfyUI 模式暂不支持，会提示）
- **删除**

悬停卡片也有快捷操作。

## 11. 常见问题与排错

### 侧栏看不到插件 / 页面空白

1. 确认插件已安装且启用：插件页里能看到 `dsh-creation-workbench`。
2. 刷新页面（`Ctrl+R`）。
3. 看日志：`%USERPROFILE%\.dsh\dsh-creation-workbench\logs\client.log` 与 `host.log`。
4. 如果日志有 `duplicate factory registration`，说明客户端模块 id 与包名不一致——重装最新版本。

### 生成失败：`生成超时（300 秒）`

**第三方 API 任务**才会受这个超时限制。如果是 ComfyUI 任务还报这个错，说明版本较旧，升级到 2.1.0+（本地任务不再设总超时）。

API 任务确实慢的话：设置 → 生成超时 调大（最大 600 秒）。

### ComfyUI 检测不通

- 确认 ComfyUI 在跑：浏览器打开 `http://127.0.0.1:8188` 能看到界面。
- 地址**不要**带 `/v1`、不要带尾部斜杠。
- 插件**不走代理**；如果系统代理拦截了 localhost，把 `127.0.0.1` 加入直连例外。

### 导入工作流报「UI 格式」

你导出的不是 API 格式。回 ComfyUI 用 **Save (API format)** 重新导出。

### 工作流能导入但提示词进不去

检查编辑器里的 **「主提示词」** 绑定。没绑定的话，对话框会显示警告按钮，点它回到编辑器选择一个文本输入作为主提示词。

### 生成结果和预期不符（步数/尺寸/种子不对）

- 检查该工作流参数是否勾选并保存。
- 不同工作流的参数 key 相同（`p_1`、`p_2`…），但值**按会话 + 按工作流分别存储**，切换工作流不会串。
- 随机参数每次生成后会在对话框回显本次实际值。

### 切换会话后工作流变了

2.1.0+ 已按会话隔离。若仍出现，确认版本 ≥ 2.1.0（设置里能看到版本，或看 `package.json`）。

### `@` 没有弹出模板

- 输入框打 `@` 后需要**紧跟文字或等待面板**；如果 `@` 前面不是空格/行首可能不触发。
- 模板库为空时面板会提示「去模板标签新建」。
- 快捷键：`Esc` 关闭。

### Agent 生成报「没有可用的 DSH 模型服务」

- 只有 **DSH 桌面端** 才暴露宿主模型服务。
- 确认 DSH 里已经配置并可用至少一个模型。
- 或者把 Agent 来源切回 **Agent API**。

### Agent 图片反推不可用

DSH 模型通道只支持文字。要用图片反推，必须在 Agent 设置里选 **Agent API**，并配置支持视觉的模型（如 `gpt-4o-mini` / `qwen-vl-plus`）。

### 图片文件名冲突 / 找不到图片

图片按 `工作区名/会话名/图片ID` 存放。改了工作区或会话名后，**新图**进入新目录，**旧图**仍在旧目录，记录里存的是绝对路径，所以旧图仍能打开。

### 数据迁移（1.x → 2.x）

首次启动日志里会记录 `.migrated-from-image-workbench`。旧目录 `%USERPROFILE%\.dsh\dsh-image-workbench` **保留不删**（其中的图片绝对路径仍被旧会话引用）。确认新版本一切正常后，可以自行备份后删除旧目录。
